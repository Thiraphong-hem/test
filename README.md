# วนดี — Google Sheets + Apps Script

ใช้งานผ่าน Google Apps Script Web App ไม่มี Node.js หรือเซิร์ฟเวอร์ที่ต้องดูแล

## ติดตั้ง
1. เปิด https://script.google.com สร้าง New project
2. เพิ่มไฟล์ `Code.gs` และไฟล์ HTML ชื่อ `Index`, `Styles`, `Scripts` แล้วคัดลอกเนื้อหาจากไฟล์ชื่อเดียวกันใน repository
3. เปิด Project Settings > Show appsscript.json manifest file และแทนที่ด้วยไฟล์ appsscript.json
4. เลือกฟังก์ชัน `setup` แล้วกด Run และอนุญาตสิทธิ์ Google Sheets/Drive ฟังก์ชันจะสร้างชีตและโฟลเดอร์หลักฐานให้เพียงครั้งเดียว ID อยู่ใน Script Properties ชื่อ SHEET_ID และ FOLDER_ID
5. เลือก Deploy > New deployment > Web app โดย Execute as: Me และ Who has access: Only myself สำหรับการเริ่มใช้งานส่วนตัว แล้วกด Deploy เปิด Web app URL
6. เมื่อแก้โค้ด เลือก Manage deployments > Edit > New version > Deploy

ข้อมูลขายอยู่ในแท็บ Sales โดยคอลัมน์สุดท้ายเก็บรายละเอียด JSON สำหรับแอป อย่าแก้คอลัมน์นี้ด้วยมือ ไฟล์แนบอยู่ใน Google Drive ของผู้ติดตั้ง ลิงก์หลักฐานเปิดใน Drive และยังอยู่ภายใต้สิทธิ์ของ Drive ไม่เปิดไฟล์เป็นสาธารณะอัตโนมัติ

## ใช้ร่วมกัน
กำหนดการเข้าถึง Web App เฉพาะกลุ่มที่เชื่อถือได้ตามนโยบาย Workspace ผู้เข้าถึงแอปสามารถอ่านและแก้ไขรายการทั้งหมดได้ แอปยังไม่มีสิทธิ์แยกรายบุคคล แชร์โฟลเดอร์หลักฐานให้ผู้ใช้ที่ต้องเปิดเอกสาร ห้ามตั้ง Anyone สำหรับข้อมูลส่วนตัว เพราะ Web App ทำงานด้วยสิทธิ์เจ้าของ

รองรับหลายวัสดุต่อการขาย คำนวณเงิน สถานะรับเงิน การส่งมอบ ค้นหา แก้ไข แนบภาพ/PDF รายงานรายเดือน Excel (.xlsx) และ PDF ผ่านหน้าต่างพิมพ์ ข้อมูลแชร์ผ่าน Sheets ข้ามเครื่องได้ตามสิทธิ์เข้าถึง

ไฟล์แนบไม่เกิน 10 MB ต่อไฟล์ และอยู่ภายใต้ quota ของ Apps Script/Drive การเอาไฟล์ออกจากรายการไม่ลบต้นฉบับใน Drive รายงานไม่รวมรายการยกเลิก ยอดรับเงินจัดกลุ่มตามเดือนขาย Excel ไม่รวมเอกสารแนบ

## ตรวจหลัง Deploy
สร้างรายการสองวัสดุ น้ำหนัก 12.5 กก. ราคา 3.75 บาท และ 3 กก. ราคา 5 บาท ยอดรวมควรเป็น 61.88 บาท เมื่อรับ 20 บาทต้องค้าง 41.88 บาท บันทึกแล้วโหลดใหม่ ตรวจชีตและ Drive เปิดไฟล์แนบ แก้ยอดรับเป็น 61.88 บาท ทดสอบค้นหา ส่งออก Excel และพิมพ์ PDF

ยังไม่ได้ Deploy หรือทดสอบกับบัญชี Google จริง ต้องอนุญาตสิทธิ์และทำขั้นตอนติดตั้งด้วยบัญชีของคุณก่อน
